# Buy or Rent Calculator

A mobile-friendly calculator for comparing buying a home against renting and investing the down payment plus monthly savings.

The app includes bundled city-level market defaults generated from Zillow Research public ZHVI and ZORI CSV files. The location lookup updates home price, rent, home appreciation, rent growth, property tax estimate, and insurance estimate when a matching city/state is found.

## Publish With GitHub Pages

1. Create a GitHub account at https://github.com if you do not already have one.
2. Create a new public repository.
3. Upload `index.html`, `styles.css`, `script.js`, and `market-data.js`.
4. In the repository, open Settings > Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select the `main` branch and `/root`, then save.

GitHub will provide a public URL for the calculator.
